# RaiseIt — AI-Powered Campus Issue Management Platform

RaiseIt is a full-stack MERN application designed to streamline campus issue reporting and tracking. The platform enables students to report issues digitally while allowing administrators to manage, prioritize, and monitor complaints efficiently.

## 🚀 Features

- JWT-based Authentication
- Role-Based Access Control
- Issue Reporting & Tracking
- RESTful APIs
- Responsive UI with Tailwind CSS
- Scalable Backend Architecture
- Planned AI Moderation using Google Gemini AI

## 🛠️ Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Tailwind CSS
- JWT Authentication

## 📌 Future Enhancements

- Spam & Duplicate Detection using AI
- Real-time Notifications
- Analytics Dashboard
- Multi-campus Support
